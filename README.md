### 📂 Featured Projects

**🔐 [CMMC / NIST 800-171 Home Lab Compliance Program](https://github.com/Rbroad47/nist-800-171-cmmc-home-lab)**
I treated my home network as a mock CUI environment and ran it through a full CMMC Level 2 readiness cycle: a System Security Plan with current and target network diagrams, a 49-control assessment across Access Control, Identification & Authentication, and System & Communications Protection, a risk register, a POA&M, a control matrix covering all 110 requirements, three policies, and an executive summary.
