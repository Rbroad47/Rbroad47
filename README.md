### 📂 Featured Projects

**🔐 CMMC / NIST 800-171 Home Lab Compliance Program**
I treated my home network as a mock CUI environment and ran it through a full CMMC readiness cycle: a System Security Plan with network diagram and boundary findings, a control assessment across the Access Control, Identification & Authentication, and System & Communications Protection families (49 controls), a risk register, a POA&M, and written policies.
